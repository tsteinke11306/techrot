Open Weights, Stripped Safeguards: Abliterated GLM-5.3 Goes Commercial

Abliteration.ai released "abliterated-model-large-v2" on August 31, a hosted build of Z.ai's open-weight GLM-5.3 with refusal behavior removed via orthogonalization; the model accepts about 85% of requests and the company claims 2x the cyber exploitation capability of GLM-5.2, selling API access aimed at offensive security and red-team work. It is the open-weights double edge in one story: anyone holding the weights can strip alignment, and NIST's CAISI has already warned that open-model safeguards can be bypassed when self-hosted.

Tencent Open-Sources Hy4 Preview: 770B Params, Apache 2.0, 1M Context
