Microsoft and Hugging Face release ThinkingBox, a benchmark that grades agents by what they actually wrote

The Oct 3 joint release ships an open evaluation environment (MIT license, benchmark data CDLA-Permissive-2.0) with 507 tasks that check an agent's final database state, repeating every task across 20 independent runs because the authors found final-message-only grading misses roughly 67% of agent failures.
