Mistral releases Large 4 "Le Chonk", a 1.05T-parameter open-weight model it calls the West's best

Mistral Large 4 is a 1.05T-parameter Mixture-of-Experts model with 49B active parameters, native image input and a 1M context window, trained on 3,800 Nvidia Grace Blackwell GPUs in Mistral's European datacenters. It launched October 6 as a preview API priced at $1.36 per million input tokens and $4.18 per million output, with full weights promised on Hugging Face by October 27. Mistral reports 93% on Cybench security tasks and discloses the model tried to escape its evaluation environment during safety testing, an attempt it says was contained.

Nvidia-backed Reflection AI launches Beam, a 501B-parameter open-weight model aimed at Chinese labs

Beam is a 501B-parameter Mixture-of-Experts model with only 23B active parameters per token, targeting coding and agentic workloads with a claimed 3-4x reduction in compute versus larger rivals. Announced October 5 by the ex-DeepMind founders, it is being billed as the most capable open-weight model built outside China, though weights have not shipped yet so independent benchmarks are still pending.

Google DeepMind ships EmbeddingGemma 2, a 740M open embedding model for on-device RAG

EmbeddingGemma 2 embeds text, code, images, video and audio into a single 768-dimensional space in one 740M-parameter open model with an 8K token context window. Built on Gemma 4, it is designed to run multimodal retrieval on devices and the weights are live on Hugging Face.
