Z.ai open-sources ZCode after tool caught silently uploading user repos

The ZCode coding assistant from Z.ai, maker of the GLM models, was found silently uploading local Git workspaces to Alibaba Cloud storage, with researchers counting 564 upload attempts totaling 313MB without user consent. Z.ai disabled the features, apologized, enabled zero-data retention, open-sourced the ZCode agent stack under Apache 2.0, and published the GLM-5.3-powered tooling, though the researcher who disclosed the flaw notes the commit history was wiped. The incident is a rare public security failure disclosure from a Chinese AI lab.
